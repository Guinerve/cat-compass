# Cat Compass design

Baseline: [Notion DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/notion/DESIGN.md).
Adapt the workspace layout, quiet borders, type scale and tinted cards. Keep Cat Compass's warm palette. Do not copy the marketing page.

## Direction

Warm, quiet, practical. A left rail separates care tools from the reference library. The daily view puts the selected cat, tasks and food plan first. Use local SVG art, not remote images or tracking fonts.

## Tokens

- Canvas: `#f7f6f2`; card: `#ffffff`; ink: `#253c36`.
- Muted: `#626d65`; border: `#dfE4dd`.
- Primary: `#246653`; peach: `#f7e7d9`; mint: `#e8f0e6`.
- Alert: `#a63127`. Show a word and icon with each alert.
- Dark mode follows the system setting. Canvas `#151b19`, card `#1d2522`, ink `#e4ebe6`, primary `#7cc4a8`.
- Type: system sans for controls; Georgia for large editorial headings. No body or label text below 12 px.
- Spacing: 4, 8, 12, 16, 24, 32, 48 px. Cards: 20 px radius.

## Components and layout

Use a 238 px rail and a flexible content area on desktop. At 900 px, put navigation above the page. At 600 px, use one column. Do not hide safety notices on phones. Keep form controls available when a plan is invalid. Show units in every food input. Source cards show publisher, exact page, checked date, supported claims and limits.

## Access

Use labelled controls, visible keyboard focus, and text for chart values. Keep body copy at 16 px. Support reduced motion. Use confirmation before data removal or import. Errors must name the failed input. Print only the care sheet.
