# Community rules

Keep discussion useful, respectful and safe.

- Discuss the work, not a person's worth or background.
- No harassment, threats, hate speech, sexual content or disclosure of private information.
- Explain disagreement with evidence. Correct errors without personal attacks.
- Do not post private owner records or give individual treatment instructions in issues.
- Respect source rights. Do not upload copied articles, images or private application captures.

Maintainers may edit or remove harmful content, close a thread or restrict participation. Use GitHub's **Report content** controls for abuse. Use the [private security channel](SECURITY.md) only for security findings.

This repository is not an emergency service or a clinical consultation forum.
