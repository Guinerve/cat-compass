# Roadmap

This is a direction, not a schedule. Safety, keeping records intact and trusted releases come before new features.

1. **Vet review.** Get a named vet to review the care content, with a stated scope and date. Fix or remove any claim the review does not support.
2. **Real devices.** Install the app on real iOS and Android phones and check calendar alerts. Run the Intel Mac, Windows and Linux packages, including alerts and uninstall.
3. **Signed releases.** Add code signing and macOS notarisation.
4. **Time zones.** Keep repeating calendar events at the same local time across daylight saving changes.

Not planned: cloud accounts, live sync, diagnosis, medicine doses, insurance advice, milk feeds for newborn kittens and homemade diet recipes.
