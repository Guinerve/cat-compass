# Roadmap

This list is a direction, not a delivery schedule. Safety, record preservation and release trust take priority over more features.

## Before a trusted general release

- Obtain a veterinary review with a named scope and date. Correct or withhold unsupported clinical claims.
- Complete real iOS/Android installation and imported calendar-alert checks.
- Drive Intel Mac, Windows and Linux packages, including notifications and uninstall behaviour.
- Add code signing and macOS notarization. Document publisher identity and release verification.
- Review development packaging advisories and keep dependencies current.
- Resolve the ACT containment birthday boundary with an authoritative current source.

## Care-tool improvements

- Better food-label entry and explicit unit conversion controls.
- Calendar timezone handling across daylight-saving changes.
- More accessible body-condition teaching, with source rights respected.
- Richer vet-visit and pet-sitter exports without exposing records by default.
- More source-reviewed life-stage and region guides.

## Not promised

Cloud accounts, live household sync, diagnosis, medication dosing, insurance advice, neonatal feeds and homemade diet formulation are not part of this release. Any future network service needs a separate privacy and security design.

[Suggest an improvement](https://github.com/Guinerve/cat-compass/issues/new/choose). State the owner task and expected result. Do not attach private pet records.
