# Cat Compass 0.2.0 · early access

A local care space for your cat, with desktop packages, an offline-capable web app and phone calendar reminders.

## Download

Choose an attached file for your computer:

- Apple Silicon Mac: `Cat-Compass-0.2.0-mac-arm64.dmg`.
- Intel Mac: `Cat-Compass-0.2.0-mac-x64.dmg`.
- Windows 64-bit: `Cat-Compass-0.2.0-win-x64.exe`.
- Linux 64-bit: `Cat-Compass-0.2.0-linux-x64.AppImage`.

Mac ZIP archives are also supplied. Download `SHA256SUMS.txt` and compare your file's complete hash. Only use a file once it appears among the release assets.

[Installation guide](https://github.com/Guinerve/cat-compass/blob/v0.2.0/docs/installation.md) · [Open the HTTPS web app](https://guinerve.github.io/cat-compass/)

## Included

- A new daily care dashboard, separate cat profiles and vet contacts.
- Label-based wet/dry food amounts with strict validation and treats deducted from the daily total.
- 15 original guides and 31 exact source records.
- Weight history, care notes, reminders, checklists and printable handover.
- Local backups, phone calendar export and password-protected QR snapshot transfer.

## Checked

61 unit tests and 24 browser tests pass locally. The packaged Apple Silicon macOS app passed offline launch, renderer isolation, native schedule persistence and close-to-tray checks. Other platform package builds do not replace runtime testing on those platforms.

## Limits you need to know

**All desktop packages are unsigned.** The macOS app is not notarized. Do not disable system security to install it. Export a backup before upgrading. No automatic desktop updater is included.

**The app is not veterinary-approved.** It does not diagnose, prescribe medicine or calculate neonatal milk feeds. Use your vet's instructions for clinical care. Guidance is mainly Australian-facing. The ACT 1 July 2022 birthday boundary remains unresolved.

Calendar exports and QR transfers are copies, not live sync. Full backups are unencrypted. Calendar alerts depend on the calendar provider. Native alerts need the app running and system permission. Real iOS/Android installation, audible alerts and Intel Mac/Windows/Linux runtime checks remain open.
